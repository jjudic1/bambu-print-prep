# handoff3d-video

Nine vertical promo videos for [Handoff3D](https://bambu-print-prep.vercel.app),
built with [Remotion](https://remotion.dev) and rendered locally. 1080x1920 at
30fps -- the native frame for YouTube Shorts, TikTok and Instagram Reels.

```powershell
npm install
npm run dev          # Remotion Studio on http://localhost:8142
npm run render:all   # every cut into out/
```

See [CLAUDE.md](CLAUDE.md) for what each cut is for and where the copy comes
from.
