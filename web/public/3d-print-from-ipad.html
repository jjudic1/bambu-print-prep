3D printing from an iPad, with no computer

It is possible to go from a model you downloaded to an object on the plate using nothing but an iPad and a Bambu Lab printer. The step that used to need a desktop — preparing the file — now runs in Safari. The step after it, sending the file to the machine, has always been possible through Bambu Handy. This page is the whole route, end to end.

Open Handoff3D

Free, no account, nothing installed. Works in Safari on an iPad or an iPhone.

The three things that have to happen

1. Find a model. MakerWorld, Printables and Thingiverse all work in Safari. A download lands in Files, under Downloads.

2. Prepare it. Size it, stand it the right way up, and turn it into a file your printer understands. This is the part that used to need Bambu Studio on a desktop. Handoff3D does it in the browser.

3. Send it. Bambu does not let other apps talk to your printer directly, so the file goes up to your own private page on MakerWorld, and Bambu Handy prints it from there. It is a handful of taps, once per model.

Why step three is clunky, and why it is not your fault

There is no public way for a third-party app to hand a file to a Bambu printer. The machine takes work from Bambu's own software, and from Bambu's own cloud. So the file travels: iPad → your private MakerWorld page → Bambu Handy → printer. Set the model to Private when you upload it and nobody else ever sees it.

Every file comes with a page of these steps saved next to it, because there are several places to get lost and you will want it again next time. The steps are written out on getting the file to the printer.

Does it work on an iPhone?

Yes. It is the same page and the same route. An iPad is more comfortable for judging size on the bed, but nothing here needs the bigger screen.

What it costs

Nothing. There is no account, no sign-in, and no upload of your model. Visits are counted anonymously, so it is possible to tell whether anybody is finding it; the model, its name and everything measured from it stay on your device.

Common questions

Can you 3D print from an iPad without a computer?

Yes, with a Bambu Lab printer. Prepare the file in Safari with Handoff3D, upload it as a private model on MakerWorld, and print it from the Bambu Handy app. No desktop computer is involved at any point.

Does it work on an iPhone as well as an iPad?

Yes. The same page works on an iPhone, and the steps are identical.

Can Bambu Handy prepare a model on its own?

No. Bambu Handy sends and monitors prints and browses MakerWorld. It cannot take a downloaded model and turn it into something printable — that is the gap this fills.
